# Sparks design specification

Direction: restrained Swiss editorial typography, pure white background, open layouts and thin gray rules. Public wording and content come from the Ghost source. No new marketing sections.

- White #ffffff, ink #111114, muted #71717a, rule #e4e4e7, accent #a020c0.
- Self-hosted Inter Variable. Wordmark 44px, desktop masthead 72px, feature title 36px, row titles 25px, body 19px / 1.8, UI 14px. Mobile masthead 42px, article title 32px.
- Main container 1200px, reading container 740px. Header, masthead, two-column feature, ruled article rows, compact footer.
- Header links Home and About with Search. Existing site slogan is the only homepage headline.
- Lead image has no tint, overlay, gradient or shadow. All cover photos must be real source assets. Concept images illustrate layout only.
- Source truth corrections: use actual cover images, original publication dates and original title spelling instead of invented/repeated dates and photos in the concept.
- Components: wordmark, navigation, search dialog, feature, article rows, pagination, reading layout, publishing table, editor.
- Search, archive, pagination, article, author, tag, RSS and accessible keyboard paths must work.
- Neon-backed Studio: protected login, article list, draft editing, visual rich-text editor, metadata, preview, media upload, publishing.
